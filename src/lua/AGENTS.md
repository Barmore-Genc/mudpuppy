Embedded Luau scripting: the configurable keymap and event hooks. A sandboxed interpreter (no io/os/network/subprocess) where all default bindings live in Lua; user config loads on top, last-binding-wins. Bindings are keyed on key *sequences* (multi-key chords, a `<leader>`, and ambient count prefixes); a `:command` palette runs named commands. Scripts read the diff/files/annotations/screen and drive the app through scoped action verbs.

- `mod.rs`: `LuaEngine` (sandbox setup, `core.luau` + user-config load/hot-reload), the sequence-dispatch state machine (pending count + partial sequence on `App`, prefix-wait/exact/miss resolution), `run_command`/`run_prompt`, leader/command/prompt/update-check/file-filter/debug-log registries (`debug_log()` getter — a bool — the binary reads at startup), `apply_file_filters` (hide files via the `filter_files` predicates; `unhide-files` command + `toggle_file_filters` verb reveal them), `EventKind` (incl. `UpdateCheck`/`fire_update_check` and `SkillUpdateCheck`/`fire_skill_update_check`), `active_mode` (which keymap an open overlay selects), `config_path` (hand-rolled XDG resolver), and `config_help`/`default_config` (what `mudpuppy config` prints).
- `api.rs`: builds the `mudpuppy` table — persistent `map`/`unmap`/`on`/`command`/`leader`/`filter_files`, the settable `debug_log` field (a `__newindex` metamethod takes a boolean to toggle logging; not a path, so a config can't redirect log writes), the `mudpuppy.updates` sub-table (`check`/`update`/`check_enabled`/`set_check_enabled`/`disable`, the last persisting the opt-out to config), the `mudpuppy.skills` sub-table (`check`/`refresh`/`skip` for refreshing stale installed Claude Code skills), and the `mudpuppy.anchor` sub-table (`advanced_match_window`/`fallback_match_window` getter-setter pairs for the two relocation scan windows), plus the per-dispatch scoped action/reader fns that borrow `&mut App` via a `RefCell` (including `open_palette`, `prompt`, `move_selection`, the writable `state()` proxy, and the overlay verbs — `help_*`/`picker_*`/`palette_*`/`prompt_*`/`composer_*`/`confirm_delete`/`cancel_delete` — the overlay keymap modes are built from).
- `keys.rs`: `KeyChord` (parse/`from_event`/round-trip), `parse_sequence` (+ `<leader>` expansion), the `KeySeq` alias, the count-digit rule, `Key`, and the `Mode` enum — the pane modes (`Global`/`Tree`/`Diff`) plus the exclusive overlay modes (`Help`/`Picker`/`Palette`/`Prompt`/`DeleteConfirm`/`Composer`/`ComposerInsert`/`ComposerNormal`), with `chain` (the fallback order) and `takes_count`.
- `views.rs`: read-only Lua tables built on demand from the live `App` — `files`/`current_file`/`annotations`/`screen` (and the shared `file_summary` the `filter_files` predicate receives), the `state()` proxy's `state_field`/`set_state_field` (the only writable field is `count`; the `help`/`composer`/`prompt` sub-tables are nil unless that overlay is open), plus shared annotation/turn builders.
- `core.luau`: the embedded default keymap (Space leader, count-aware motions, `:command` palette commands, and the overlay keymaps — help scroll, picker/palette nav, prompt options, delete confirm, and the composer's Ctrl-S save / severity / tag / mode keys) plus the auto-update flow (`update_check` handler + `check-updates` command + the install/ignore/skip prompt) and the stale-skill refresh flow (`skill_update_check` handler + update/not-now/skip prompt), expressed against the primitive verbs; `include_str!` in release, read from disk in debug so it hot-reloads in dev.
