The ratatui diff viewer, split into the event-loop shell, the state, and the
drawing.

- `mod.rs`: module root — `launch` (also turns mouse capture on/off), the `run_loop` event loop (terminal input, mouse events, store reload, config hot-reload, the periodic update-check timer gated by `MUDPUPPY_NO_UPDATE_CHECK`, modal-prompt key capture), the notify watchers, and the `Snapshot`/`fire_changes` event-hook diffing.
- `app.rs`: viewer state — `App` and its verbs (count-aware scroll/cursor move/`move_selection`/hunk-hop, visual selection, select, focus, release turn, reload), the `Sidebar` tab (Files/Annotations) and its `sidebar_*` nav/jump verbs + `annotation_list`, the pending count/sequence fields, the `:command` palette state + `handle_palette_key`, the `Hits` hit-test struct + `handle_mouse_event` (wheel/click/drag/double-click), plus `Focus`, `Row`, and the lazily-built per-file `FileView`.
- `annotate.rs`: the user's annotation mutations (`impl App`) — cursor/selection → anchor, add/region/file/reply/edit/delete/status writes through `store::update`, and the delete-confirm key handler.
- `composer.rs`: the comment composer (`Composer`, `ComposerTarget`, `Mode`) with a vim-like modal text buffer (normal/insert, line+cursor edits), its key handler (`handle_composer_key`), and the composer-opening verbs (`add_comment`/`comment_file`/`reply`/`edit_comment`).
- `prompt.rs`: the modal question overlay (`Prompt`) opened from Lua via `mudpuppy.prompt`; `open_prompt` + `handle_prompt_key` (nav/dismiss, returns the chosen option index the engine runs). Labels live here; option callbacks live in the engine.
- `render.rs`: per-frame drawing — one function per pane (the sidebar's file tree / all-annotations tab, diff, status, help, banner) plus the picker, `:command` palette, and modal-prompt overlays, the status-bar pending count/sequence hint, row → styled-line, the small style/format helpers, and per-frame population of `App::hits` (pane rects + clickable label spans) for the mouse handler; defines `MARK`.
- `tests/`: Layer-1 `insta` snapshot + buffer-style tests driving the real keymap through `App::handle_key`; `mod.rs` holds the shared fixtures/helpers, with tests grouped by topic into `rendering`, `keymap`, `annotations`, `turns`, `expansion`, `authoring`, `mouse`.
- `tests/snapshots/`: generated `insta` `.snap` baselines for the tests here.
